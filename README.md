# java-lotto-precourse

## 기능 목록

### 정상 기능

1. 로또 구입 금액 입력 받기
   - 1,000원 단위로 입력받기
   - 구입 금액에 맞는 개수의 로또 발행
2. 발행된 로또 번호 출력
   - 발행 개수 표시
   - 각 로또 번호 오름차순 정렬하여 출력
3. 당첨 번호 입력 받기
   - 쉼표로 구분된 6개 번호 입력
4. 보너스 번호 입력 받기
   - 1개의 보너스 번호 입력
5. 당첨 통계 계산 및 출력
   - 당첨 등급별 일치 개수 및 당첨금 표시
   - 총 수익률 계산 및 출력

### 예외 처리

1. 구입 금액 검증
   - 1,000원으로 나누어 떨어지지 않는 경우
   - 숫자가 아닌 경우
   - 음수이거나 0인 경우
2. 로또 번호 검증
   - 번호 개수가 6개가 아닌 경우
   - 중복된 번호가 있는 경우
   - 범위(1~45)를 벗어난 경우
3. 당첨 번호 검증
   - 번호 개수가 6개가 아닌 경우
   - 중복된 번호가 있는 경우
   - 범위(1~45)를 벗어난 경우
   - 보너스 번호와 중복되는 경우
4. 보너스 번호 검증
   - 범위(1~45)를 벗어난 경우
   - 당첨 번호와 중복되는 경우
